0.3 點號、函數、物件（本課最重要的文法）

把 obj 想成「一台已經造好的機器」。.（點）的意思是「去用這台機器上的某個功能或某個讀數」。

本課會反覆出現的形狀
obj = LinearRegression()     # 造一台「線性迴歸機器」（還是空的）
obj.fit(X, y)                # 請它學習：把 X, y 餵進去，算出參數
y_hat = obj.predict(X_new)   # 請它預測
print(obj.coef_)             # 讀出它記住的斜率（屬性，沒有括號）
寫法這是什麼
LinearRegression()造物件。類別名稱 + 空括號 = 做出一個實例。括號裡可放設定，如 Ridge(alpha=0.1)。
obj.fit(X, y)方法（method）：機器會做的動作。有括號，因為在「做事」。位置引數：第一個是 \(X\)，第二個是 \(y\)。
obj.predict(X_new)另一個方法。回傳預測值，用 = 存起來。
obj.coef_屬性（attribute）：機器上記住的數字。沒有括號。sklearn 規定：fit 之後才有的屬性，名字以底線 _ 結尾。
return_X_y=True關鍵字引數：用名字指定，不必記順序。讀成「把名叫 return_X_y 的開關設成 True」。

對照：fit 像「解 \(\min J(\theta)\)」；predict 像「代入 \(f(x)=\theta^\top x\)」；coef_ 就是 \(\theta\)。

0.4 清單、編號從 0 開始、切片

清單（list）是用方括號排成一列的東西，很像有限數列。

xs = [1, 2, 3]     # 三個數字
xs[0]                # → 1  第一個。編號從 0 起，不是從 1
xs[-1]               # → 3  負號：從尾巴數
xs[-20:]             # 從倒數第 20 個一直到結尾（少於 20 個就全拿）
語法作用
[a, b, c]做出清單。
xs[i]取第 \(i\) 格（0 是第一格）。對應向量的第 \(i\) 個分量，但電腦從 0 數。
xs[start:stop]切片：半開區間 \([start, stop)\)。省略 start 或 stop 代表從頭／到尾。
xs[-20:]最後 20 筆。講義用來當訓練集。
X[:, :2]二維切片：逗號前是列、後是欄。: 表示「全部列」，:2 表示「前兩欄」（編號 0 與 1）。
( 'poly', 某物件 )tuple 元組：小括號、不可隨意改。Pipeline 用它來「給這一步取名字」。
小白最容易錯
數學寫 \(x_1\) 當第一個分量；Python 清單第一個是 x[0]。看到 coef_[0] 請讀成「斜率那一格」，不是「第 0 個特徵」的數學下標 0。

0.6 NumPy：把線性代數打進電腦

NumPy 的 ndarray 就是向量／矩陣。本課只用這幾招：

import numpy as np
X = np.c_[np.ones(3), [1,2,3]]   # 3×2 矩陣：左邊全 1（截距），右邊 x
y = np.array([2., 3., 5.])
theta = np.linalg.solve(X.T @ X, X.T @ y)  # 解 (XᵀX) θ = Xᵀy
y_hat = X @ theta                          # 矩陣乘向量 = 預測值
寫法數學
np.array([2., 3., 5.])向量 \(y\in\mathbb{R}^3\)。點 2. 強調是小數。
np.ones(3)全 1 向量 \((1,1,1)^\top\)，給截距欄用。
np.c_[A, B]把兩欄左右併成矩陣（c = column）。
X.T轉置 \(X^\top\)。
@矩陣乘法。對應你寫的 \(X\theta\)、\(X^\top X\)。不要用 *（那是逐元素相乘）。
np.linalg.solve(A, b)解 \(A\theta=b\)。比先求反矩陣 inv 再乘更穩。

第 1 章　線性迴歸工作流

來源：Lecture 2: Supervised Learning。貫穿例子：用 BMI 預測糖尿病風險分數。整章只做四件事——放資料、選一條直線、讀出預測、看誤差。

1.1 現場只發生三件事

決策 監督式學習的流程（不是定理，是工作順序）
\[ \text{Dataset} + \text{Learning Algorithm} \;\to\; \text{Predictive Model} \]
這在算什麼左邊是輸入（資料 + 你選的演算法），右邊是輸出（一條可以拿來預測的線／函數）。
儀表讀法資料本身不會給答案；必須先選模型、再擬合，才有「對新 \(x\) 的預測」。
程式哪一行obj.fit(X_train, y_train) 完成「學習」；之後的 obj.predict(X_new) 才是「預測模型」。
你要會的應用報告時分開講：我用什麼資料、選什麼模型、擬合後預測什麼。
  • Dataset：成對的 \((x,y)\)。此例 \(x=\) BMI，\(y=\) 風險分數。
  • Learning algorithm：模型類別（直線）+ 誤差儀表（MSE）+ 優化器（fit）。
  • Predictive model：擬合後的 \(f(x)\)。你真正拿去用的是這個。

1.2 糖尿病資料：儀表上的 \(X\) 和 \(y\)

sklearn 的 UCI Diabetes：442 人、10 個特徵、目標是一年後疾病進展分數。講義把 BMI 還原成約真實量級（bmi * 30 + 25），取最後 20 筆當訓練。

資料 訓練集（你餵給 fit 的東西）
\[ \mathcal{D}=\{(x^{(i)}, y^{(i)})\}_{i=1}^{n} \]
這在算什麼不在「算」。這是資料本身：第 \(i\) 個病人的輸入 \(x^{(i)}\) 與已知答案 \(y^{(i)}\)。
儀表讀法上標 \((i)\) = 第幾個樣本。下標 \(j\) = 第幾個特徵。不要把上標當次方。
程式哪一行X_train = diabetes_X.iloc[-20:]、y_train = diabetes_y.iloc[-20:]。X.shape 在 sklearn 是 (n, d)：列=樣本、欄=特徵。
你要會的應用能指出：哪裡是特徵、哪裡是標籤；sklearn 的 X 和講義 \(d\times n\) 矩陣差一個轉置。
Python · 每一行在做什麼
from sklearn import datasets
diabetes_X, diabetes_y = datasets.load_diabetes(return_X_y=True, as_frame=True)  # 資料：X 特徵、y 目標
diabetes_X = diabetes_X.loc[:, ['bmi']] * 30 + 25                                # 資料：只留 BMI 並還原量級
X_train = diabetes_X.iloc[-20:]                                                 # 資料：訓練輸入
y_train = diabetes_y.iloc[-20:]                                                 # 資料：訓練答案

1.3 這條線在預測什麼

預測值 線性模型（模型類別）
\[ f(x)=\theta_1 x + \theta_0 \qquad\text{多特徵：}\quad f(x)=\theta_0+\theta_1 x_1+\cdots+\theta_d x_d=\theta^\top x \]
這在算什麼預測值。輸入 BMI（或一排特徵），輸出模型認為的風險分數。
儀表讀法\(\theta_1\) 是斜率：BMI 每加 1，預測風險加多少。\(\theta_0\) 是截距：線與縱軸交點；BMI 不會是 0，截距通常不當「真實風險」來解釋。
程式哪一行擬合後：obj.coef_[0] 是 \(\theta_1\)，obj.intercept_ 是 \(\theta_0\)。預測：obj.predict(X) 就是 \(f(x)\)。
你要會的應用口述：「這條線在預測：給定 BMI，糖尿病風險分數。」講義得到 \(\theta_1\approx 37.38\)，意思是 BMI 高 1，預測風險約高 37 分（相關，不是因果）。

不同的 \((\theta_0,\theta_1)\) 是不同直線。學習 = 在所有直線裡挑一條。這叫選參數，還不是選模型家族（直線 vs 多項式才是選模型）。

1.4 參數是哪一行算出來的

fit 內部在做：找讓訓練誤差最小的 \(\theta\)。線性迴歸的閉式解叫普通最小平方 OLS；你不必手算，但要知道儀表上這個 \(\theta^\star\) 是參數，不是預測值。

參數 fit 求出的 \(\theta^\star\)（OLS）
\[ \theta^\star=(X^\top X)^{-1}X^\top y \]
這在算什麼參數。斜率和截距。不是某個病人的預測分數。
儀表讀法這條公式的輸出會寫進 coef_ / intercept_。之後所有預測都用這組固定參數。
程式哪一行obj.fit(X_train, y_train) ← 整行都在算 \(\theta^\star\)。等價手寫：np.linalg.solve(X.T@X, X.T@y)（\(X\) 需自行加上全 1 欄當截距）。
你要會的應用會解釋係數；不必在考試外手算反矩陣。特徵很多或損失不是平方時，fit 改走迭代（梯度下降），你仍然只呼叫 fit。

1.6 誤差儀表：MSE（以及 L1）

誤差 均方誤差 MSE（LinearRegression 內建最小化的東西）
\[ J(\theta)=\frac{1}{2n}\sum_{i=1}^n\bigl(f_\theta(x^{(i)})-y^{(i)}\bigr)^2 \]
這在算什麼誤差。預測值和答案差多少，平方後平均。前因子 \(\tfrac12\) 只為了微分好看，不改誰最小。
儀表讀法愈小愈貼。大誤差被平方放大，所以離群點會把線拉歪。L1 誤差 \(\frac1n\sum|f-y|\) 對離群較穩，但 sklearn 預設線性迴歸用的是 MSE。
程式哪一行from sklearn.metrics import mean_squared_error
mean_squared_error(y_train, y_hat_train) ← 訓練誤差
mean_squared_error(y_test, y_hat_test) ← 這個才拿來評模型
你要會的應用講義多特徵線性模型：訓練 MSE \(\approx1118\)，3 筆測試 \(\approx668\)；亂數預測約 \(16000\)。比較模型時對齊同一測試集。選次數、選 \(\lambda\) 用驗證集 MSE，最後一次才看測試集。

fit 做的事寫成儀表就是 \(\min_\theta J(\theta)\)：轉動參數，直到訓練 MSE 不能再小。這只能保證「訓練集擬合好」，不能保證測試好。

第 2 章　選一條彎的線（多項式迴歸）

來源：Polynomial Regression。直線不夠彎時，不是換一套優化器，而是換特徵：把 \(x,x^2,\ldots,x^p\) 加進去，LinearRegression 照舊。

2.1 特徵映射在算什麼

資料 多項式特徵（還不是預測）
\[ \phi(x)=\begin{bmatrix}1\\x\\x^2\\\vdots\\x^p\end{bmatrix}, \qquad f_\theta(x)=\sum_{j=0}^{p}\theta_j x^j=\theta^\top\phi(x) \]
這在算什麼\(\phi(x)\) 是資料轉換（新特徵）。\(\theta^\top\phi(x)\) 才是預測值。\(\theta\) 仍是參數。
儀表讀法對 BMI 非線性（曲線），對參數仍是線性，所以還能 fit。次數 \(p\) 是你選的旋鈕，不是 fit 算出來的。
程式哪一行PolynomialFeatures(degree=p).fit_transform(X) ← 算 \(\phi(x)\)
LinearRegression().fit(phi, y) ← 算參數 \(\theta\)
model.predict(X_new) ← 算預測值
實務用 Pipeline 串起來，避免對測試集洩漏。
你要會的應用選 \(p\)：太小欠擬合，太大過擬合。用驗證／holdout MSE 選，不要看「訓練曲線有多貼」。

講義原文曾寫 \(\sum \theta_p x^p\)，應為 \(\sum_j \theta_j x^j\)。

PolynomialFeatures(degree=2).fit_transform([[2]]) 這句可以拆開讀：造一個「二次特徵機器」→ 立刻對資料 [[2]]（注意：外層清單表示「一批樣本」，內層 [2] 是「這筆有一個特徵，值是 2」）做轉換 → 得到 [[1, 2, 4]] 即 \((1,x,x^2)\)。連著寫 A().b() 叫串接：前一個的結果當後一個的物件。

2.2 怎麼選次數 \(p\)

\(p\) 是 超參數：它決定模型有多彎，但不是 fit 從訓練損失裡學出來的。講義在 BMI 20 點上畫 \(p=1,3,5,10,20\)：次數升高，訓練曲線愈貼，並不表示愈好。

超參數 次數 \(p\)（選模型，不是算參數）
\[ p \in \{1,2,3,\ldots\} \quad\text{你指定；fit 只負責在該 }p\text{ 下算 }\theta \]
這在算什麼不在算。這是你的選擇：模型有多複雜。
儀表讀法看holdout / 驗證 MSE。訓練 MSE 隨 \(p\) 下降幾乎必然；測試 MSE 會先降後升（過擬合）。
程式哪一行PolynomialFeatures(degree=p) 的 degree。用迴圈試一組 \(p\)，每組都 fit 在訓練集、評分在驗證集。
你要會的應用選使驗證 MSE 最低的 \(p\)。多特徵時項數是 \(\binom{d+p}{p}\)，很快爆炸 → 第 4 章用正則化。

第 3 章　分類：預測的是類別／機率

來源：Classification and Logistic Regression。\(y\) 不再是分數，而是類別。名稱叫 logistic regression，工作是分類。

3.1 分類要預測什麼

  • 迴歸：線的高度 = 預測的連續值。
  • 分類：平面被切成幾塊區域，新點落在哪塊就預測哪個 class。界線叫 decision boundary。

3.2 分數 → 機率

預測值 線性分數　再　機率 Sigmoid
\[ z=\theta^\top x, \qquad f_\theta(x)=\sigma(z)=\frac{1}{1+e^{-z}}=P_\theta(y=1\mid x) \]
這在算什麼\(z\) 是分數（可正可負）。\(\sigma(z)\) 是機率（被擠進 0 到 1）。決策時通常 \(\sigma\ge 0.5\) 則預測正類，等價於 \(z\ge 0\)。
儀表讀法\(\sigma=0.92\) 讀成「模型估計屬於正類的機率約 92%」，不是迴歸分數 0.92。\(\sigma=0.5\) 的位置就是決策邊界。
程式哪一行logreg.decision_function(X) ≈ \(z\)
logreg.predict_proba(X)[:,1] = \(\sigma(z)\)
logreg.predict(X) = 類別（把機率切成 0/1）
你要會的應用解釋：「這條邊界把 Setosa 和非 Setosa 切開；此點 \(P(\text{Setosa})\approx 0.92\)。」

性質只要會用：\(z\to+\infty\) 機率趨近 1；\(z=0\) 時 \(\sigma=0.5\)。導數 \(\sigma(1-\sigma)\) 是優化器內部用的，你呼叫 fit 即可。

互動 3 · \(\sigma(\theta_1 x+\theta_0)\)：斜率改變時繞 \(x=0\) 那一點變陡

\(z=\theta_1 x+\theta_0\)。在 \(x=0\) 處 \(z=\theta_0\)，所以曲線永遠通過紅點 \(\bigl(0,\sigma(\theta_0)\bigr)\)。只改 \(\theta_1\)：紅點不動，曲線繞它變陡或變緩。虛線 \(0.5\) 是決策閾值，交點在 \(x=-\theta_0/\theta_1\)（會隨斜率移動，這是對的）。

3.3 分類的誤差儀表（交叉熵）

誤差 二元交叉熵（fit 在最小化的東西）
\[ J(\theta)=-\frac1n\sum_i\Bigl[y^{(i)}\log p^{(i)}+(1-y^{(i)})\log(1-p^{(i)})\Bigr], \quad p=\sigma(\theta^\top x) \]
這在算什麼誤差。機率預測得有多離譜。答對且很有把握 → 損失接近 0；把 1 說成 0.01 → 損失很大。
儀表讀法這是訓練用的損失。對外報告分類好不好，通常改看 accuracy（對幾成）或錯誤率，而且要在測試集上算。
程式哪一行logreg.fit(X, y) 內部最小化交叉熵（外加一點正則化，由 \(C=1/\lambda\) 控制）。
報告：logreg.score(X_test, y_test) = 測試準確率。
你要會的應用不要用訓練準確率宣稱模型強。選 \(C\) 用驗證集。

3.4 Softmax：多類的機率儀表

機率 Softmax（三類以上）
\[ P(y=k\mid x)=\frac{e^{\theta_k^\top x}}{\sum_{\ell}e^{\theta_\ell^\top x}} \]
這在算什麼每個類一個分數 \(\theta_k^\top x\)，指數後再除以總和 → 一組加起來為 1 的機率。
儀表讀法輸出向量例如 \((0.7,0.2,0.1)\)：預測第 1 類，因為 0.7 最大。兩類時 softmax 就是 sigmoid，不必當新算法。
程式哪一行LogisticRegression(multi_class='multinomial').fit(X,y)
predict_proba 給 \(K\) 維機率；predict 取 argmax。

4.3 Ridge：把過大的參數壓小

過擬合的高次多項式，權重往往極大（講義看到 \(10^3\)–\(10^7\)）。Ridge = 線性迴歸的 MSE 再加上「參數別太大」。

誤差 + 參數懲罰 Ridge 目標
\[ J(\theta)=\frac{1}{2n}\sum_i\bigl(y^{(i)}-\theta^\top\phi(x^{(i)})\bigr)^2+\frac{\lambda}{2}\lVert\theta\rVert_2^2 \] 閉式（fit 在解這個）：\(\theta=(X^\top X+\lambda I)^{-1}X^\top y\)
這在算什麼第一項仍是訓練誤差；第二項是參數大小。\(\lambda\) 是超參數：愈大，權重被壓得愈小，曲線愈平滑。
儀表讀法\(\lambda=0\) 就是普通 OLS。\(\lambda\) 太大會欠擬合（線太平）。sklearn 把 \(\lambda\) 叫 alpha。
程式哪一行Ridge(alpha=0.1).fit(X, y) ← 算參數
不要寫 Ridge(alpha=0).fit 還以為有正則化。
你要會的應用高次多項式仍想用時，加 Ridge。\(\lambda\) 在驗證集上選。截距通常不正則化（sklearn 預設如此）。特徵先 StandardScaler。
為什麼不能在訓練集上選 \(\lambda\)
若把 \(\lambda\) 也對訓練損失最小化，優化器會把它設成 0（等於取消懲罰）。所以 \(\lambda\) 必須用驗證誤差選。

4.4 Lasso：把沒用的特徵變成 0

參數 L1 懲罰 → 稀疏
\[ J(\theta)=\frac1n\sum L(y,\theta^\top x)+\lambda\sum_j|\theta_j| \]
這在算什麼仍然是「誤差 + 懲罰參數」。換成絕對值後，許多 \(\theta_j\) 會正好變成 0（稀疏 = 自動特徵選擇）。
儀表讀法Ridge：係數縮小但很少到 0。Lasso：沒用的線會貼在 0。要解釋「哪些特徵被留下」就用 Lasso。
程式哪一行Lasso(alpha=λ).fit(X_scaled, y) 或 LassoCV(...).fit（交叉驗證選 \(\alpha\)）

應用例題 5 · 十個特徵只有三個有用：誰該用 Ridge、誰該用 Lasso

題目

用 make_regression 做出 80 筆、10 個特徵、其中只有 3 個真正影響 \(y\) 的假資料。請：(1) 先標準化；(2) 切訓練／測試；(3) 分別 fit Ridge(alpha=1) 與 LassoCV；(4) 印出兩種模型的測試 MSE；(5) 印出 Lasso 哪些係數不是 0。最後寫兩句：這條線在預測什麼；你若要「解釋哪些變數有用」該交哪一個模型。

選哪個模型？ \(y\) 連續 → 迴歸。特徵多、可能無關 → 若要穩定用 Ridge；若要自動丟掉變數用 Lasso。\(\lambda\)（sklearn 叫 alpha）用驗證／CV 選，不能在訓練集上選。

from sklearn.datasets import make_regression
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge, LassoCV
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error
import numpy as np

X, y = make_regression(n_samples=80, n_features=10, n_informative=3,
                       noise=8, random_state=0)
X = StandardScaler().fit_transform(X)        # 各欄減平均、除標準差
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, random_state=0)

ridge = Ridge(alpha=1.0).fit(X_tr, y_tr)
lasso = LassoCV(cv=5).fit(X_tr, y_tr)        # 內部用驗證折選 alpha

print('Ridge 測試 MSE', mean_squared_error(y_te, ridge.predict(X_te)))
print('Lasso 測試 MSE', mean_squared_error(y_te, lasso.predict(X_te)))
print('Lasso 選到的 alpha', lasso.alpha_)
print('Lasso 係數', np.round(lasso.coef_, 3))
print('非零特徵編號', np.where(np.abs(lasso.coef_) > 1e-6)[0])
這一行語法在幹嘛在算什麼
make_regression(n_samples=80, n_features=10, n_informative=3, noise=8, random_state=0)全部是關鍵字引數：80 筆、10 欄、3 欄真正有訊號、再加雜訊。回傳 X, y。假資料（方便你核對 Lasso 有沒有找回那 3 欄）
StandardScaler().fit_transform(X)串接：造標準化器並立刻轉換。正則化前必做，否則單位大的欄會被不公平懲罰。資料轉換
test_size=0.25測試佔 25%。切分
Ridge(alpha=1.0).fit(X_tr, y_tr)造完立刻在訓練集 fit。測試集不能放進來。參數（L2）
LassoCV(cv=5).fit(...)cv=5：訓練集再切 5 折選 alpha，等於用驗證誤差選 \(\lambda\)。超參數 + 參數
mean_squared_error(y_te, ...predict(X_te))只在測試集評分。這才拿來比較 Ridge 與 Lasso。測試誤差
np.round(lasso.coef_, 3)每個係數留 3 位小數。讀參數
np.where(np.abs(lasso.coef_) > 1e-6)[0]哪些位置的絕對值大於極小值。[0] 取出編號陣列。Lasso 留下的特徵

這條線在預測什麼： 用 10 個數字輸入，預測一個連續的 \(y\)（假的「銷量／風險」）。Ridge 會 10 個係數都還在（縮小）；Lasso 應大約只留下 3 個非零——那就是「自動特徵選擇」。

交作業時怎麼寫： 「比較兩個模型用測試 MSE。若目的是解釋哪些變數有用，交 Lasso 的非零係數；若只在乎預測穩，Ridge 通常更穩。」不要寫訓練 MSE 當結論。

進階提醒：更嚴謹時，StandardScaler 只在訓練集上 fit，再 transform 測試集，避免用到測試集的平均。上面為了短，是對全部 \(X\) 標準化。

自己改一改： 把 n_informative=3 改成 10（每個特徵都有用），看 Lasso 還會不會砍成 3 個——這時不該再為了稀疏而硬用很大的 \(\lambda\)。
