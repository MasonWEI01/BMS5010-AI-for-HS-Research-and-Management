0.3 點號、函數、物件（本課最重要的文法）

把 obj 想成「一台已經造好的機器」。.（點）的意思是「去用這台機器上的某個功能或某個讀數」。

本課會反覆出現的形狀
obj = LinearRegression()     # 造一台「線性迴歸機器」（還是空的）
obj.fit(X, y)                # 請它學習：把 X, y 餵進去，算出參數
y_hat = obj.predict(X_new)   # 請它預測
print(obj.coef_)             # 讀出它記住的斜率（屬性，沒有括號）
寫法這是什麼
LinearRegression()造物件。類別名稱 + 空括號 = 做出一個實例。括號裡可放設定，如 Ridge(alpha=0.1)。
obj.fit(X, y)方法（method）：機器會做的動作。有括號，因為在「做事」。位置引數：第一個是 \(X\)，第二個是 \(y\)。
obj.predict(X_new)另一個方法。回傳預測值，用 = 存起來。
obj.coef_屬性（attribute）：機器上記住的數字。沒有括號。sklearn 規定：fit 之後才有的屬性，名字以底線 _ 結尾。
return_X_y=True關鍵字引數：用名字指定，不必記順序。讀成「把名叫 return_X_y 的開關設成 True」。

對照：fit 像「解 \(\min J(\theta)\)」；predict 像「代入 \(f(x)=\theta^\top x\)」；coef_ 就是 \(\theta\)。

0.4 清單、編號從 0 開始、切片

清單（list）是用方括號排成一列的東西，很像有限數列。

xs = [1, 2, 3]     # 三個數字
xs[0]                # → 1  第一個。編號從 0 起，不是從 1
xs[-1]               # → 3  負號：從尾巴數
xs[-20:]             # 從倒數第 20 個一直到結尾（少於 20 個就全拿）
語法作用
[a, b, c]做出清單。
xs[i]取第 \(i\) 格（0 是第一格）。對應向量的第 \(i\) 個分量，但電腦從 0 數。
xs[start:stop]切片：半開區間 \([start, stop)\)。省略 start 或 stop 代表從頭／到尾。
xs[-20:]最後 20 筆。講義用來當訓練集。
X[:, :2]二維切片：逗號前是列、後是欄。: 表示「全部列」，:2 表示「前兩欄」（編號 0 與 1）。
( 'poly', 某物件 )tuple 元組：小括號、不可隨意改。Pipeline 用它來「給這一步取名字」。
小白最容易錯
數學寫 \(x_1\) 當第一個分量；Python 清單第一個是 x[0]。看到 coef_[0] 請讀成「斜率那一格」，不是「第 0 個特徵」的數學下標 0。

0.6 NumPy：把線性代數打進電腦

NumPy 的 ndarray 就是向量／矩陣。本課只用這幾招：

import numpy as np
X = np.c_[np.ones(3), [1,2,3]]   # 3×2 矩陣：左邊全 1（截距），右邊 x
y = np.array([2., 3., 5.])
theta = np.linalg.solve(X.T @ X, X.T @ y)  # 解 (XᵀX) θ = Xᵀy
y_hat = X @ theta                          # 矩陣乘向量 = 預測值
寫法數學
np.array([2., 3., 5.])向量 \(y\in\mathbb{R}^3\)。點 2. 強調是小數。
np.ones(3)全 1 向量 \((1,1,1)^\top\)，給截距欄用。
np.c_[A, B]把兩欄左右併成矩陣（c = column）。
X.T轉置 \(X^\top\)。
@矩陣乘法。對應你寫的 \(X\theta\)、\(X^\top X\)。不要用 *（那是逐元素相乘）。
np.linalg.solve(A, b)解 \(A\theta=b\)。比先求反矩陣 inv 再乘更穩。

題目

三位同學讀書時數是 1、2、4 小時。你先不要擬合，而是用手寫的直線 \(f(x)=10x+50\) 當「猜的模型」（預測考試分數）。請用 Python：把時數放進清單、用迴圈算出每位的預測分數並印出來，最後再印出三人預測的平均。

這題在練什麼：變數、=、清單、算術、for、print。對應儀表：這裡算出來的是預測值，不是參數（參數 10 與 50 是你自己寫死的）。

解題步驟：① 存資料 ② 對每個 \(x\) 代入 \(10x+50\) ③ 印出來 ④ 求平均。

hours = [1, 2, 4]              # 資料：三個 x，清單從 0 編號
preds = []                       # 空清單，等一下把預測值一個個放進去
for x in hours:                  # 依序把 1、2、4 放進變數 x
    y_hat = 10 * x + 50          # 預測值：就是 f(x)=10x+50
    preds.append(y_hat)          # 方法 append：把 y_hat 接到清單尾巴
    print('讀書', x, '小時 → 預測', y_hat, '分')
avg = sum(preds) / len(preds)    # sum 加總、len 個數。這是平均，還不是 MSE
print('平均預測', avg)
這一行語法在幹嘛在算什麼
hours = [1, 2, 4]造清單，存進名字 hours。資料 \(x\)
preds = []空清單，稍後往裡加東西。用來收集預測值
for x in hours:迴圈。冒號不能省；下面縮排的行會重複三次。對每個樣本做同一件事
y_hat = 10 * x + 50* 是乘。這不是 fit，是你手寫的公式。預測值
preds.append(y_hat)點號+括號 = 方法。把一個數字接到尾巴。累積預測
print('讀書', x, ...)字串與數字用逗號隔開一起印。給人看
sum(preds) / len(preds)內建函數 sum、len。除號是 /。平均預測（還不是誤差）

你應該看到： 1 小時→60 分，2 小時→70 分，4 小時→90 分，平均約 73.3。請口述：「這條線在預測考試分數；斜率 10 表示每多讀 1 小時，預測多 10 分。」下一步（例題 2）才會讓電腦自己找出斜率和截距。

第 1 章　線性迴歸工作流

1.1 現場只發生三件事

決策 監督式學習的流程（不是定理，是工作順序）
\[ \text{Dataset} + \text{Learning Algorithm} \;\to\; \text{Predictive Model} \]
這在算什麼左邊是輸入（資料 + 你選的演算法），右邊是輸出（一條可以拿來預測的線／函數）。
儀表讀法資料本身不會給答案；必須先選模型、再擬合，才有「對新 \(x\) 的預測」。
程式哪一行obj.fit(X_train, y_train) 完成「學習」；之後的 obj.predict(X_new) 才是「預測模型」。
你要會的應用報告時分開講：我用什麼資料、選什麼模型、擬合後預測什麼。
  • Dataset：成對的 \((x,y)\)。此例 \(x=\) BMI，\(y=\) 風險分數。
  • Learning algorithm：模型類別（直線）+ 誤差儀表（MSE）+ 優化器（fit）。
  • Predictive model：擬合後的 \(f(x)\)。你真正拿去用的是這個。

1.3 這條線在預測什麼

預測值 線性模型（模型類別）
\[ f(x)=\theta_1 x + \theta_0 \qquad\text{多特徵：}\quad f(x)=\theta_0+\theta_1 x_1+\cdots+\theta_d x_d=\theta^\top x \]
這在算什麼預測值。輸入 BMI（或一排特徵），輸出模型認為的風險分數。
儀表讀法\(\theta_1\) 是斜率：BMI 每加 1，預測風險加多少。\(\theta_0\) 是截距：線與縱軸交點；BMI 不會是 0，截距通常不當「真實風險」來解釋。
程式哪一行擬合後：obj.coef_[0] 是 \(\theta_1\)，obj.intercept_ 是 \(\theta_0\)。預測：obj.predict(X) 就是 \(f(x)\)。
你要會的應用口述：「這條線在預測：給定 BMI，糖尿病風險分數。」講義得到 \(\theta_1\approx 37.38\)，意思是 BMI 高 1，預測風險約高 37 分（相關，不是因果）。

不同的 \((\theta_0,\theta_1)\) 是不同直線。學習 = 在所有直線裡挑一條。這叫選參數，還不是選模型家族（直線 vs 多項式才是選模型）。

1.4 參數是哪一行算出來的

fit 內部在做：找讓訓練誤差最小的 \(\theta\)。線性迴歸的閉式解叫普通最小平方 OLS；你不必手算，但要知道儀表上這個 \(\theta^\star\) 是參數，不是預測值。

參數 fit 求出的 \(\theta^\star\)（OLS）
\[ \theta^\star=(X^\top X)^{-1}X^\top y \]
這在算什麼參數。斜率和截距。不是某個病人的預測分數。
儀表讀法這條公式的輸出會寫進 coef_ / intercept_。之後所有預測都用這組固定參數。
程式哪一行obj.fit(X_train, y_train) ← 整行都在算 \(\theta^\star\)。等價手寫：np.linalg.solve(X.T@X, X.T@y)（\(X\) 需自行加上全 1 欄當截距）。
你要會的應用會解釋係數；不必在考試外手算反矩陣。特徵很多或損失不是平方時，fit 改走迭代（梯度下降），你仍然只呼叫 fit。
Python · 擬合 = 算參數；predict = 算預測值

obj.fit(X_train, y_train.values)          # 參數：算出 θ1, θ0

y_hat_train = obj.predict(X_train)        # 預測值：訓練點上的 f(x)

預測值 新樣本

儀表讀法紅叉 = 模型猜的風險；紅點 = 真實風險（模型訓練時沒看過）。兩者差多少才是「新資料表現」。

1.6 誤差儀表：MSE（以及 L1）

誤差 均方誤差 MSE（LinearRegression 內建最小化的東西）
\[ J(\theta)=\frac{1}{2n}\sum_{i=1}^n\bigl(f_\theta(x^{(i)})-y^{(i)}\bigr)^2 \]
這在算什麼誤差。預測值和答案差多少，平方後平均。前因子 \(\tfrac12\) 只為了微分好看，不改誰最小。
儀表讀法愈小愈貼。大誤差被平方放大，所以離群點會把線拉歪。L1 誤差 \(\frac1n\sum|f-y|\) 對離群較穩，但 sklearn 預設線性迴歸用的是 MSE。
程式哪一行from sklearn.metrics import mean_squared_error
mean_squared_error(y_train, y_hat_train) ← 訓練誤差
mean_squared_error(y_test, y_hat_test) ← 這個才拿來評模型
你要會的應用講義多特徵線性模型：訓練 MSE \(\approx1118\)，3 筆測試 \(\approx668\)；亂數預測約 \(16000\)。比較模型時對齊同一測試集。選次數、選 \(\lambda\) 用驗證集 MSE，最後一次才看測試集。

fit 做的事寫成儀表就是 \(\min_\theta J(\theta)\)：轉動參數，直到訓練 MSE 不能再小。這只能保證「訓練集擬合好」，不能保證測試好。

第 2 章　選一條彎的線（多項式迴歸）

來源：Polynomial Regression。直線不夠彎時，不是換一套優化器，而是換特徵：把 \(x,x^2,\ldots,x^p\) 加進去，LinearRegression 照舊。

2.1 特徵映射在算什麼

資料 多項式特徵（還不是預測）
\[ \phi(x)=\begin{bmatrix}1\\x\\x^2\\\vdots\\x^p\end{bmatrix}, \qquad f_\theta(x)=\sum_{j=0}^{p}\theta_j x^j=\theta^\top\phi(x) \]
這在算什麼\(\phi(x)\) 是資料轉換（新特徵）。\(\theta^\top\phi(x)\) 才是預測值。\(\theta\) 仍是參數。
儀表讀法對 BMI 非線性（曲線），對參數仍是線性，所以還能 fit。次數 \(p\) 是你選的旋鈕，不是 fit 算出來的。
程式哪一行PolynomialFeatures(degree=p).fit_transform(X) ← 算 \(\phi(x)\)
LinearRegression().fit(phi, y) ← 算參數 \(\theta\)
model.predict(X_new) ← 算預測值
實務用 Pipeline 串起來，避免對測試集洩漏。
你要會的應用選 \(p\)：太小欠擬合，太大過擬合。用驗證／holdout MSE 選，不要看「訓練曲線有多貼」。

講義原文曾寫 \(\sum \theta_p x^p\)，應為 \(\sum_j \theta_j x^j\)。

PolynomialFeatures(degree=2).fit_transform([[2]]) 這句可以拆開讀：造一個「二次特徵機器」→ 立刻對資料 [[2]]（注意：外層清單表示「一批樣本」，內層 [2] 是「這筆有一個特徵，值是 2」）做轉換 → 得到 [[1, 2, 4]] 即 \((1,x,x^2)\)。連著寫 A().b() 叫串接：前一個的結果當後一個的物件。

Python · Pipeline 三行分別在算什麼
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression

2.2 怎麼選次數 \(p\)

\(p\) 是 超參數：它決定模型有多彎，但不是 fit 從訓練損失裡學出來的。講義在 BMI 20 點上畫 \(p=1,3,5,10,20\)：次數升高，訓練曲線愈貼，並不表示愈好。

超參數 次數 \(p\)（選模型，不是算參數）
\[ p \in \{1,2,3,\ldots\} \quad\text{你指定；fit 只負責在該 }p\text{ 下算 }\theta \]
這在算什麼不在算。這是你的選擇：模型有多複雜。
儀表讀法看holdout / 驗證 MSE。訓練 MSE 隨 \(p\) 下降幾乎必然；測試 MSE 會先降後升（過擬合）。
程式哪一行PolynomialFeatures(degree=p) 的 degree。用迴圈試一組 \(p\)，每組都 fit 在訓練集、評分在驗證集。

第 3 章　分類：預測的是類別／機率

來源：Classification and Logistic Regression。\(y\) 不再是分數，而是類別。名稱叫 logistic regression，工作是分類。

3.1 分類要預測什麼

  • 迴歸：線的高度 = 預測的連續值。
  • 分類：平面被切成幾塊區域，新點落在哪塊就預測哪個 class。界線叫 decision boundary。
  • \(K=2\) 是二元分類；Iris 有 3 類（Setosa / Versicolour / Virginica），150 朵、4 個公分特徵。

3.2 分數 → 機率

預測值 線性分數　再　機率 Sigmoid
\[ z=\theta^\top x, \qquad f_\theta(x)=\sigma(z)=\frac{1}{1+e^{-z}}=P_\theta(y=1\mid x) \]
這在算什麼\(z\) 是分數（可正可負）。\(\sigma(z)\) 是機率（被擠進 0 到 1）。決策時通常 \(\sigma\ge 0.5\) 則預測正類，等價於 \(z\ge 0\)。
儀表讀法\(\sigma=0.92\) 讀成「模型估計屬於正類的機率約 92%」，不是迴歸分數 0.92。\(\sigma=0.5\) 的位置就是決策邊界。
程式哪一行logreg.decision_function(X) ≈ \(z\)
logreg.predict_proba(X)[:,1] = \(\sigma(z)\)
logreg.predict(X) = 類別（把機率切成 0/1）
你要會的應用解釋：「這條邊界把 Setosa 和非 Setosa 切開；此點 \(P(\text{Setosa})\approx 0.92\)。」

性質只要會用：\(z\to+\infty\) 機率趨近 1；\(z=0\) 時 \(\sigma=0.5\)。導數 \(\sigma(1-\sigma)\) 是優化器內部用的，你呼叫 fit 即可。

互動 3 · \(\sigma(\theta_1 x+\theta_0)\)：斜率改變時繞 \(x=0\) 那一點變陡

\(z=\theta_1 x+\theta_0\)。在 \(x=0\) 處 \(z=\theta_0\)，所以曲線永遠通過紅點 \(\bigl(0,\sigma(\theta_0)\bigr)\)。只改 \(\theta_1\)：紅點不動，曲線繞它變陡或變緩。虛線 \(0.5\) 是決策閾值，交點在 \(x=-\theta_0/\theta_1\)（會隨斜率移動，這是對的）。

3.3 分類的誤差儀表（交叉熵）

誤差 二元交叉熵（fit 在最小化的東西）
\[ J(\theta)=-\frac1n\sum_i\Bigl[y^{(i)}\log p^{(i)}+(1-y^{(i)})\log(1-p^{(i)})\Bigr], \quad p=\sigma(\theta^\top x) \]
這在算什麼誤差。機率預測得有多離譜。答對且很有把握 → 損失接近 0；把 1 說成 0.01 → 損失很大。
儀表讀法這是訓練用的損失。對外報告分類好不好，通常改看 accuracy（對幾成）或錯誤率，而且要在測試集上算。
程式哪一行logreg.fit(X, y) 內部最小化交叉熵（外加一點正則化，由 \(C=1/\lambda\) 控制）。
報告：logreg.score(X_test, y_test) = 測試準確率。
你要會的應用不要用訓練準確率宣稱模型強。選 \(C\) 用驗證集。

3.4 Softmax：多類的機率儀表

機率 Softmax（三類以上）
\[ P(y=k\mid x)=\frac{e^{\theta_k^\top x}}{\sum_{\ell}e^{\theta_\ell^\top x}} \]
這在算什麼每個類一個分數 \(\theta_k^\top x\)，指數後再除以總和 → 一組加起來為 1 的機率。
儀表讀法輸出向量例如 \((0.7,0.2,0.1)\)：預測第 1 類，因為 0.7 最大。兩類時 softmax 就是 sigmoid，不必當新算法。
程式哪一行LogisticRegression(multi_class='multinomial').fit(X,y)
predict_proba 給 \(K\) 維機率；predict 取 argmax。
你要會的應用Iris 三類：解釋「這點最可能是 Virginica，機率 …」。One-vs-all 是備案：每類一個「我 vs 其餘」。

第 4 章　測試誤差才算數；用正則化選更穩的模型

來源：Regularization。玩具資料 \(y=\cos(1.5\pi x)+\varepsilon\)。次數 1 太直（欠擬合），次數 30 穿過每個訓練點但在點之間亂晃（過擬合）。

4.1 兩種失敗：用兩塊儀表診斷

診斷訓練誤差Holdout／測試誤差你要做的
欠擬合 underfitting高高加特徵、加次數、換更有彈性的模型、確認有 fit 成功

可用低低再拿到測試集上做最後一次確認
誤差 好模型的定義（Applied ML 的評分規則）
\[ \frac1m\sum_{i=1}^m L\bigl(\dot y^{(i)}, f_\theta(\dot x^{(i)})\bigr) \quad\text{在 holdout／測試集上} \]
這在算什麼誤差（或 1−準確率）。點號 \(\dot x\) 表示「沒拿來訓練的點」。
儀表讀法迴歸用 MSE；分類常用錯誤率 \(\frac1m\sum\mathbb{I}(\hat y\neq y)\)。這個數字才代表新資料。

4.3 Ridge：把過大的參數壓小

過擬合的高次多項式，權重往往極大（講義看到 \(10^3\)–\(10^7\)）。Ridge = 線性迴歸的 MSE 再加上「參數別太大」。

誤差 + 參數懲罰 Ridge 目標
\[ J(\theta)=\frac{1}{2n}\sum_i\bigl(y^{(i)}-\theta^\top\phi(x^{(i)})\bigr)^2+\frac{\lambda}{2}\lVert\theta\rVert_2^2 \] 閉式（fit 在解這個）：\(\theta=(X^\top X+\lambda I)^{-1}X^\top y\)
這在算什麼第一項仍是訓練誤差；第二項是參數大小。\(\lambda\) 是超參數：愈大，權重被壓得愈小，曲線愈平滑。
儀表讀法\(\lambda=0\) 就是普通 OLS。\(\lambda\) 太大會欠擬合（線太平）。sklearn 把 \(\lambda\) 叫 alpha。
程式哪一行Ridge(alpha=0.1).fit(X, y) ← 算參數
不要寫 Ridge(alpha=0).fit 還以為有正則化。
你要會的應用高次多項式仍想用時，加 Ridge。\(\lambda\) 在驗證集上選。截距通常不正則化（sklearn 預設如此）。特徵先 StandardScaler。
為什麼不能在訓練集上選 \(\lambda\)
若把 \(\lambda\) 也對訓練損失最小化，優化器會把它設成 0（等於取消懲罰）。所以 \(\lambda\) 必須用驗證誤差選。

4.4 Lasso：把沒用的特徵變成 0

參數 L1 懲罰 → 稀疏
\[ J(\theta)=\frac1n\sum L(y,\theta^\top x)+\lambda\sum_j|\theta_j| \]
這在算什麼仍然是「誤差 + 懲罰參數」。換成絕對值後，許多 \(\theta_j\) 會正好變成 0（稀疏 = 自動特徵選擇）。
儀表讀法Ridge：係數縮小但很少到 0。Lasso：沒用的線會貼在 0。要解釋「哪些特徵被留下」就用 Lasso。
程式哪一行Lasso(alpha=λ).fit(X_scaled, y) 或 LassoCV(...).fit（交叉驗證選 \(\alpha\)）
然後看 lasso.coef_ 哪些是 0。

第 5 章　決策樹與隨機森林（Tree-Based Models）

前面幾章的模型都在學一條（彎的）線或一張機率表。本週換成另一類監督式模型：決策樹（Decision Tree）——它用一連串「是／否」問題把特徵空間切成矩形區域，每個區域給一個預測。樹可以做分類也可以做迴歸。單棵樹好解釋，但很容易過擬合（高變異）；把很多棵樹的預測平均起來，就是 Bagging 與 隨機森林（Random Forest）。

5.1 像人一樣問問題

決策樹在模仿人類看病／分類的流程：

  1. 先挑一個特徵（例如年齡）。
  2. 用一個門檻分支：年齡 > 65？是走右邊、否走左邊。
  3. 再挑下一個特徵繼續問（例如是不是男性）。
  4. 問完走到葉子，給一個答案（例如「65 歲以上男性 → 高風險」）。

和線性模型的差別：它不假設 \(y\) 跟 \(x\) 成直線。切出來的是一塊塊矩形（決策區域）。小樹好讀；樹太深就會把訓練集背下來。

5.2 糖尿病風險：一棵深度 2 的樹

講義把糖尿病資料的連續風險分數切成兩類：風險 > 150 叫「高風險」（\(y=1\)），否則 \(y=0\)。只用前四欄：age、sex、bmi、bp。造一棵 max_depth=2 的分類樹。

預測值 決策樹：區域上的常數
\[ f(x)=\sum_{R\in\mathcal{R}} y_R\,\mathbb{I}\{x\in R\} \] 其中 \(\mathbb{I}\{\cdot\}\) 是指示函數（條件成立為 1，否則 0）；\(y_R\) 是區域 \(R\) 的預測（分類=該區最多的類別，迴歸=該區 \(y\) 的平均）。
這在算什麼預測值。\(x\) 只會落在一個區域，所以 \(f(x)\) 就是那個葉上的 \(y_R\)。
儀表讀法葉子愈多、矩形愈碎 → 模型愈複雜。深度 2 最多 4 片葉，剛好還能用嘴巴講完。
程式哪一行DecisionTreeClassifier(max_depth=2).fit(X, y) ← 學切法（參數）
clf.predict(X_new) ← 預測值
plot_tree(clf, ...) ← 把樹畫出來給人讀
你要會的應用指著樹說：「BMI 高且血壓高的人，模型預測高風險。」最終好不好仍看測試集準確率，不要看訓練集有多純。

講義那棵深度 2 的樹，大意是：

  1. 根節點問 BMI 是否 \(\le 0.009\)（資料已標準化，所以門檻看起來像小數）。
  2. BMI 高的人再問血壓；血壓也高 → 多數是高風險（講義數字：86 人裡約 76 人高風險）。
  3. 你對新病人做預測時：從最上面開始，每次只看一個特徵、一個門檻，走到葉子，葉子寫的類別就是 predict 的答案。

這就是 \(f(x)=\sum_R y_R\mathbb{I}\{x\in R\}\)：新 \(x\) 掉進哪一塊矩形，就用那一塊的 \(y_R\)。

5.3 決策規則、決策區域：只能切矩形

決策 一條決策規則（通常只看一個特徵）
\[ r(x)=\begin{cases} \mathrm{True} & \text{若 }x_{\mathrm{bmi}}\le 0.009\\ \mathrm{False} & \text{若 }x_{\mathrm{bmi}}> 0.009 \end{cases} \]
這在算什麼把特徵空間切成兩半。連續特徵幾乎都是「\(\le c\) vs \(> c\)」。多個門檻可以拆成一連串簡單規則，不必一次寫複雜區間。
儀表讀法內部節點 = 一條規則；往左／往右 = 規則的 True/False；葉子 = 預測。
程式哪一行fit 內部在挑「哪一欄 + 哪個 \(c\)」。plot_tree 看到的 bmi <= 0.009 就是 \(r(x)\)。
你要會的應用解釋模型時沿根走到葉，寫成人話規則。不要把樹當成「斜率 37 的直線」。

決策區域（Decision region）是一路問下來的條件交集，例如

\[ R=\{x:x_{\mathrm{bmi}}\le 0.009\text{ 且 }x_{\mathrm{bp}}>0.004\}. \]

葉子 \(\leftrightarrow\) 區域。在兩個特徵 \(X_1,X_2\) 的平面上，這些區域一定是軸對齊的矩形（切線水平或垂直）。斜著切的、中間挖洞的形狀，單棵二元決策樹做不出來——那不是風格問題，是模型家族的限制。

和邏輯迴歸決策邊界的差別
第 3 章的邏輯迴歸邊界是一條直線（\(\theta^\top x=0\)）。決策樹的邊界是一堆水平／垂直切線組成的階梯。樹很深時階梯會碎成很多小格子——看起來「很準」，常常是過擬合。

5.4 怎麼學：葉子要「純」，CART 貪心往下切

fit 不會一次找全宇宙最好的樹（那太難），而是 CART：每次挑當下讓葉子最純的一刀，切完再對子節點重複。這叫貪心（greedy）。分類常用誤分類率、Gini、entropy；迴歸常用葉內 MSE。

誤差／不純度 分類：誤分類率（葉上預測該區最多的類別）
\[ L(\mathcal{D}_R)=\frac{1}{|\mathcal{D}_R|}\sum_{(x,y)\in\mathcal{D}_R}\mathbb{I}\bigl\{y\neq \texttt{most-common-y}(\mathcal{D}_R)\bigr\} \]
這在算什麼如果這片區域現在就是葉子，預測眾數類別，會錯幾成。愈小愈「純」：同一類擠在一起。
儀表讀法\(L=0\) 表示這片全是同一類。Gini \(1-\sum_c p_c^2\)、entropy 也是同一精神：類別不要混。
程式哪一行sklearn 分類樹預設 criterion='gini'。fit 內部用它挑切法；你對外報告仍看測試準確率。
你要會的應用訓練不純度低 ≠ 模型好。深度太大時訓練 \(L\to 0\)，測試卻變差——回到第 4 章的過擬合。
誤差 迴歸樹：葉上預測該區平均，損失是平方和
\[ L(\mathcal{D}_R)=\sum_{(x,y)\in\mathcal{D}_R}\bigl(y-\texttt{average-y}(\mathcal{D}_R)\bigr)^2 \]
這在算什麼迴歸時葉子是一個數字（平均 \(y\)），\(L\) 就是這片的平方誤差。
程式哪一行DecisionTreeRegressor(max_depth=...)。評估仍用測試 MSE。
你要會的應用連續 \(y\) 用迴歸樹；0/1 或三類用分類樹。不要把 Classifier 拿去預測血糖這種連續分數。
演算法名片：CART
  • 類型：監督式（迴歸與分類）。
  • 模型家族：決策樹（軸對齊矩形區域上的常數）。
  • 目標：平方誤差／誤分類／Gini／entropy。
  • 優化器：貪心加規則，再視需要修剪（pruning）。sklearn 常用 max_depth、min_samples_leaf 當「先別長太大」的剎車。
優點
好解釋；不太需要標準化；連續／類別特徵都能用；分類迴歸同一套想法。
缺點
小樹不夠強；大樹很容易過擬合、難正則化。單棵深度不限的樹，換一批訓練資料會長得很不一樣（高變異）。

5.6 高變異：換一批資料，模型跳得很厲害

第 4 章的過擬合，換一個說法叫高變異（high variance）：訓練集稍微改一點，學出來的 \(f\) 差很多，到沒看過的 \(x\) 就亂預測。講義先用高次多項式示範：同一 \(p=6\)，三次隨機抽 20 個點，三條曲線長得完全不一樣。決策樹深度夠大時也是同一種病——Iris 上不限深度的樹，邊界呈碎階梯，而且三個隨機子集會長出三張不像的地圖。

常見誤解
「訓練準確率 100% 所以這棵樹很強。」——那只代表它把訓練點背起來了。換一批 bootstrap 樣本，切法會整張重畫。單棵深樹的測試表現通常不穩。

5.7 Bagging：把很多「亂跳」的模型平均掉

Bagging = Bootstrap Aggregation。 做法：有放回地抽很多份跟原資料一樣大的子集（bootstrap 樣本），每一份各訓練一個模型，預測時把答案平均（迴歸）或投票（分類）。直觀：單一模型的隨機錯誤正負會對消。

預測值 裝袋後的預測（分類可改成投票）
\[ f_{\mathrm{bag}}(x)=\frac1M\sum_{m=1}^M f_m(x) \] 每個 \(f_m\) 是在一份 bootstrap 樣本上 fit 出來的。
這在算什麼預測值（集成）。\(M\) 是你設的超參數（幾棵／幾個模型）。
儀表讀法\(M=1\) 就是單模型。\(M\) 加大，邊界通常變平滑、變異下降。再加大到某個程度就幾乎不再變。
程式哪一行概念上是迴圈：抽樣 → fit → 存起來；預測時平均。RandomForestClassifier(n_estimators=M) 把這件事一次做完。
你要會的應用單棵樹不穩時改用森林。\(M\)、max_depth 仍用驗證集選；最終只報測試集。

親戚手法（講義點名即可）：Pasting＝不放回抽樣；Random features＝隨機抽特徵；兩者都做叫 random patches。

5.8 隨機森林：把 Bagging 用在決策樹上

講義把「bagged decision trees」叫做隨機森林：對 \(m=1\ldots M\)，有放回抽樣 → 各長一棵樹 → 預測時平均／投票。sklearn 的 RandomForestClassifier 還多做一件事：每次要切時，只在隨機抽出的一部分特徵裡挑（這才是名字裡的 random）。本課先掌握「多棵樹 + 平均降變異」；進階再調 max_features。

第 6 章　無監督學習：沒有 \(y\) 時在找結構

前面全部是監督式：資料是 \((x,y)\)，模型學 \(x\to y\)。無監督（Unsupervised learning）的資料只有 \(x\)，沒有標籤。演算法要找的是結構，而不是「預測這個人的風險分數」：

  • 分群（Clustering）：哪些病人比較像一組（電子病歷裡的相似族群）。
  • 離群值（Outliers）：哪一筆特別奇怪（可疑的檢驗值）。
  • 去噪／壓縮：從雜訊裡把訊號撈回來（本週不實作，只建立語言）。

對應講義：Week 3 Unsupervised Learning。四件應用能力改寫成無監督版：選 \(K\)／連結法（超參數）、看目標函數／輪廓係數、解釋這幾個質心代表什麼族群、不要用「有標籤才知道的準確率」來訓練（標籤若有，只拿來事後檢查，不准餵給 fit）。

6.1 食譜長得很像，但模型不再是預測機

資料 無監督資料集（沒有 \(y\)）
\[ \mathcal{D}=\{x^{(i)}\mid i=1,\ldots,n\},\qquad x^{(i)}\in\mathbb{R}^d \] \[ \underbrace{\text{Dataset}}_{\text{特徵}} + \underbrace{\text{Learning Algorithm}}_{\text{模型類 + 目標 + 優化器}} \to \text{Unsupervised Model} \]
這在算什麼輸出不是 \(\hat y\)，而是結構 \(s\)：群編號、質心、樹狀圖……
儀表讀法模型 \(f_\theta:\mathcal{X}\to\mathcal{S}\)。目標 \(J(\theta)\) 仍是「這組參數有多貼資料」，但 \(J\) 最小不自動等於「分得對」——因為沒有標準答案。
程式哪一行KMeans(...).fit(X) 只有 \(X\)，沒有 \(y\)。這是和 LinearRegression.fit(X, y) 最大的文法差別。
你要會的應用先問自己：我有沒有標籤？有 → 監督式。沒有、只想找族群 → 本週的分群。

6.2 \(K\)-means：\(K\) 個質心，一點歸最近的那團

模型參數 \(\theta\) 就是 \(K\) 個質心 \(c_1,\ldots,c_K\)。新點 \(x\) 的「結構」是：離誰最近，就歸哪一群（本課距離用歐氏距離）。

結構／分群 \(K\)-means 模型
\[ f_\theta(x)=\arg\min_k \lVert x-c_k\rVert_2 \]
這在算什麼給每個 \(x\) 一個群編號 \(1\ldots K\)。質心 \(c_k\) 是參數（學來的）；\(K\) 是超參數（你選的）。
儀表讀法質心會落在該群的平均位置。兩團分得很開時，質心也會分開；\(K\) 太大時，多餘的質心會去貼個別雜訊點。
程式哪一行KMeans(n_clusters=K).fit(X) ← 學質心
model.cluster_centers_ ← 讀 \(c_k\)
model.labels_ 或 model.predict(X_new) ← 讀 \(f(x)\)
你要會的應用解釋：「這一團質心大約是萼片短而寬的花。」不要說「準確率 90%」——訓練時根本沒有 \(y\)。
目標函數 點到所屬質心的距離平方和（sklearn 叫 inertia）
\[ J(\theta)=\sum_{i=1}^n \lVert x^{(i)}-c_{f_\theta(x^{(i)})}\rVert_2^2 \] 講義有時把平方拿掉、只寫距離和；sklearn 的 inertia_ 與 -model.score(X) 用的是平方和。數字變小代表「點更貼自己的質心」，不代表「分對品種」。
這在算什麼擬合有多緊。\(K\) 變大時 \(J\) 幾乎一定下降（更多質心更好貼點），所以不能「\(J\) 最小就最好」。
儀表讀法欠擬合：\(K\) 太小，\(J\) 仍大，一個質心被迫管兩團。過擬合：\(K\) 太大，質心去抓局部雜訊，\(J\) 很低但沒有可解釋的族群。
程式哪一行model.inertia_ 或 -model.score(X)。這是訓練目標，不是測試準確率。
你要會的應用選 \(K\) 用下一節的肘部法則／輪廓係數／專業判斷，不要交 \(J\) 最小的那個 \(K\)（那通常是你試過的最大 \(K\)）。

6.3 優化器：兩步交替，直到質心不再動

從隨機質心開始，重複直到收斂（講義保證有限步後會停：每一步 \(J\) 不增，不能無限下降）：

  1. 指派：質心不動。每個點改掛到最近的質心：\(f(x^{(i)})=\arg\min_k\lVert x^{(i)}-c_k\rVert\)。
  2. 更新：歸屬不動。每個質心搬到該群的平均：\(c_k=\mathrm{mean}\{x^{(i)}:f(x^{(i)})=k\}\)。
互動圖要對上的不變量
只做第 1 步時，菱形（質心）不准移動，只准改點的顏色。只做第 2 步時，點的顏色／歸屬不准改，只准菱形飛到該顏色的平均位置。若你看到「按指派、質心卻跳了」，那是程式寫錯，不是 K-means。
演算法名片：K-Means
  • 類型：無監督（分群）。
  • 模型家族：\(K\) 個質心。
  • 目標：到最近質心的距離（平方）和。
  • 優化器：指派 ↔ 更新 交替。

6.5 無監督的欠擬合／過擬合，以及肘部法則

講義用四團高斯當例子：

  • 欠擬合：\(K=2\)，一個質心硬管兩團，結構沒學完。
  • 合理：\(K=4\)，對上真正的團數。
  • 過擬合：\(K=10,20,50\)，質心去貼局部雜訊，\(J\) 很低但沒有可解釋的四團。

真實資料通常不是 2D、也沒有真正的標籤，不能靠「畫出來看看」或「準確率」。常用啟發式：肘部法則（Elbow method）。

超參數 肘部：畫 \(J(K)\)，找下降變慢的轉折
橫軸 \(K=1,2,\ldots\)，縱軸 \(J(K)\)（或 inertia_）。肘部 = 斜率從陡變平的地方，當作 \(K\) 的候選。
這在算什麼每個 \(K\) 都從頭 fit 一次，記錄目標函數。這是選超參數，不是再算一組質心給報告用的「準確率」。
儀表讀法\(J\) 會一直往下。轉折之後再加 \(K\)，\(J\) 幾乎只剩直線緩降——多出來的質心多半在擬合雜訊。講義例子的肘部在 \(K=4\)。
程式哪一行for k in range(1, 11): KMeans(n_clusters=k).fit(X) 然後 plt.plot(Ks, objs)。
你要會的應用肘部是候選，不是定理。還可以看輪廓係數（silhouette）、或問領域「我們預期幾種病人」。絕對不要選 \(J\) 最小的 \(K\)。

題目

用 Iris 四個特徵（不要把 target 傳進 fit）。先 StandardScaler。對 \(K=1\) 到 \(8\) 各跑一次 K-means，印出 \(K\) 與 inertia_。根據肘部你選哪個 \(K\)？用該 \(K\) 再 fit 一次，印出 cluster_centers_。最後才用 iris.target 對一下（事後檢查，不是訓練）。寫兩句：這幾個質心在描述什麼；你為什麼不選 inertia 最小的 \(K\)。

選哪個模型？ 沒有 \(y\) → K-means，不是邏輯迴歸。\(K\) 是超參數，用肘部／領域知識選。

from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

iris = load_iris()
X = StandardScaler().fit_transform(iris.data)     # 四欄量綱不同，先標準化

for k in range(1, 9):
    m = KMeans(n_clusters=k, n_init=10, random_state=0).fit(X)
    print('K', k, 'inertia', round(m.inertia_, 1))

km = KMeans(n_clusters=3, n_init=10, random_state=0).fit(X)
print('質心', km.cluster_centers_)
print('（事後才看）品種', iris.target[:5], '分群', km.labels_[:5])
這一行語法在幹嘛在算什麼
StandardScaler().fit_transform(iris.data)各欄減平均、除標準差。歐氏距離才公平。資料轉換
round(m.inertia_, 1)留一位小數，方便看肘部。目標 \(J\)
KMeans(...).fit(X)沒有第二個引數 \(y\)。參數（質心）
最後才印 iris.target這是「偷看答案」做檢查，不是 score。事後對照，不是訓練誤差

這幾個質心在預測／描述什麼： 不是預測品種名稱。每個質心是「這一團花的平均萼片／花瓣尺寸」。若 \(K=3\) 大致對上三個品種，那是意外的收穫，不是訓練目標。

6.7 階層式分群：先長整棵樹，再決定切在哪

\(K\)-means 是扁平的：你必須先給 \(K\)，只得到一層分法。階層式分群（Hierarchical clustering）長一棵樹：

  • 最底下：每一點自己一群。
  • 往上：最像的兩群合併，再合併……
  • 最上面：全部變成一群。

這棵樹畫成 樹狀圖（dendrogram），縱軸是合併時的連結距離。你可以事後才決定切在哪——不必事先知道 \(K\)。

你要選的常見選項直觀
距離歐氏、曼哈頓、cosine…連續表格常用歐氏；文字向量常用 cosine
連結（linkage）single / complete / average / Ward兩群之間的距離怎麼定義
切法指定 \(K\)，或指定距離門檻，或看圖切超參數／決策，不是 fit 學出來的
  • Single：兩群最近的一對點。容易鍊成蛇（chaining）。
  • Complete：兩群最遠的一對。團比較緊，怕離群值。
  • Average：兩群所有配對的平均距離。
  • Ward：合併後「群內變異」增加最少。只配歐氏距離；連續資料的好預設。
決策 切樹 = 選要幾群，或選「多遠才算太遠」
sklearn：AgglomerativeClustering(n_clusters=k, linkage='ward')
SciPy：sch.linkage(...) 得到連結矩陣，再用 fcluster(..., criterion='maxclust') 或 'distance' 去切。
這在算什麼連結矩陣是參數（從資料算出誰跟誰合）；切在哪是你的超參數／決策。
儀表讀法樹狀圖上垂直線很長 = 這一刀合進了很遠的東西。常在「長垂直線」底下切。
程式哪一行fit_predict(X) 一次做完 fit + 取出 labels_。silhouette_score(X, labels) 可當「團內緊、團間離」的參考（仍不是監督式準確率）。
你要會的應用資料不大、可能有套層結構（種→屬→科）時用階層式。資料很大、已知團大概是圓的，用 K-means 比較快。
Python · sklearn 凝聚分群（講義 Iris 例子）
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import AgglomerativeClustering
from sklearn.metrics import silhouette_score

iris = load_iris()
X = StandardScaler().fit_transform(iris.data)

model = AgglomerativeClustering(n_clusters=3, metric='euclidean', linkage='ward')
labels = model.fit_predict(X)          # 結構：每個點的群編號
print('silhouette', silhouette_score(X, labels))
這一行語法在幹嘛在算什麼
AgglomerativeClustering(n_clusters=3, metric='euclidean', linkage='ward')造凝聚分群器。舊版 sklearn 可能要把 metric 寫成 affinity。超參數：\(K\)、距離、連結
fit_predict(X)串接：先 fit 再回傳 labels_。無監督沒有 predict(X_new) 的統一接口（新點怎麼掛上舊樹要另說）。結構
silhouette_score(X, labels)接近 1 表示團內緊、團間離；接近 0 表示重疊；負的表示可能分錯團。沒有 \(y\) 也能算。參考儀表（不是測試準確率）
Python · SciPy 畫樹狀圖，並用距離門檻去切
import scipy.cluster.hierarchy as sch
import matplotlib.pyplot as plt

Z = sch.linkage(X, method='ward', metric='euclidean')  # 連結矩陣
labels_k = sch.fcluster(Z, t=3, criterion='maxclust')   # 切成 3 群
labels_d = sch.fcluster(Z, t=6.5, criterion='distance') # 距離>6.5 就不要合

sch.dendrogram(Z)
plt.axhline(6.5, color='red', linestyle='--')           # 畫一條水平切線
plt.ylabel('linkage distance'); plt.show()

題目

選哪個模型？ 資料只有 150 筆、特徵連續、可能有套層 → 階層式合理。Single linkage 在這題容易把不同品種鍊在一起，不當預設。

from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import AgglomerativeClustering
from sklearn.metrics import silhouette_score
import numpy as np
import scipy.cluster.hierarchy as sch

X = StandardScaler().fit_transform(load_iris().data)
lab = AgglomerativeClustering(n_clusters=3, linkage='ward').fit_predict(X)
print('silhouette', silhouette_score(X, lab))
print('各群人數', list(np.bincount(lab)))

Z = sch.linkage(X, method='ward')
cut = sch.fcluster(Z, t=3, criterion='maxclust')
print('SciPy 各群人數', list(np.bincount(cut)[1:]))  # fcluster 編號從 1 起

np.bincount(lab)數 0 出現幾次、1 出現幾次……。群編號從 0 起。各群大小
list(...)把陣列轉成普通清單，印出來較好看。—
np.bincount(cut)[1:]SciPy 的群編號從 1 起，所以丟掉位置 0。各群大小

Softmax機率predict_proba（多類）三類以上誰最大
